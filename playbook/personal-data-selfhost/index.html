为什么是这几个

  • Immich 替掉手机云相册：自动备份、人脸分组、地图相册都有
  • Stirling PDF 替掉各种在线转换：不上传，不怕泄露
  • Excalidraw 替掉画图软件：打开网页就能画，手绘风格，导出即用

用了哪些

  • Immich❌照片备份
  • Stirling PDF✅已实测文档处理
  • Excalidraw✅画图

搭建步骤 会员

  1. 先确认设备能常开：旧笔记本、NAS、或一台小主机都行，硬盘至少 100G
  2. 装 Immich 并在手机装它的 App，打开后台自动备份，等第一轮传完
  3. 装 Stirling PDF，把浏览器书签换成它，从此不再用在线转换站
  4. Excalidraw 直接用官方网页版就够，不必自己部署
  5. 设一个每月提醒，检查磁盘剩余空间

这套组合的坑 会员

  • Immich 是 AGPL 协议：自己用完全没问题，但不要拿它做成服务卖给别

  • 手机自动备份会吃流量，第一次建议在 WiFi 下跑完
