订单、通知、表格、网页抓取——这些每天重复的事不该占着人

大概花多少

一台 2 核 4G 服务器，约 ¥60/月；AI 接口按量，每月几块到几十块

为什么是这几个

  • n8n 是那个「胶水」：把微信、表格、邮箱、数据库连起来，不用写代码
  • Fabric 负责文字活：长文总结、提炼观点、改写文案，一条命令出结果
  • Browser Use 处理网页：登录、填表、比价，这些原本只能人点的事交给它

用了哪些

  • n8n⚠️已实测流程编排
  • Fabric✅已实测文字处理
  • Browser Use✅网页操作

搭建步骤 会员

  1. 先跑通 n8n：docker 一行启动，打开 5678 端口，先做一个「收到表单 → 发邮件」的流程找感觉
  2. 把最烦的那件事拆成触发条件 + 动作，写在纸上，再搬进 n8n
  3. 文字类节点接 Fabric：让 n8n 调用命令行，把长文丢进去，拿摘要回来
  4. 网页类操作先手动跑一遍 Browser Use，确认选择器稳定，再接进流程
  5. 每个流程都加失败告警（发到微信或邮箱），否则它悄悄断了你不知道

这套组合的坑 会员

  • n8n 用的是 Sustainable Use License：自己用没问题，但不能拿它做成服务卖给别人
  • Browser Use 需要 AI 接口 Key，且网站会识别自动化，登录态容易掉
  • 没有告警的自动化比没有自动化更危险——它断了你还以为在跑
  • 别一上来就做复杂流程，先做一个「一定成功」的小流程，建立信心
