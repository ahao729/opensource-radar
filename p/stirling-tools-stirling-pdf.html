我看到了什么

  • 官方文档给人印象是几百兆，docker pull 实际下载 3.5 GB

怎么用（我实测的步骤）

1拉镜像

docker pull stirlingtools/stirling-pdf:latest —— 3.5 GB，国内先配镜像加速，否则会等很久

2启动

docker run -d --name stirling -p 18080:8080 -e SECURITY_ENABLELOGIN=false stirlingtools/stirling-pdf:latest

3浏览器打开 http

//localhost:18080 ，把 PDF 拖进「合并」功能即可

剩下的坑和调优 会员
