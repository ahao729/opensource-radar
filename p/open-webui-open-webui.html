怎么用（我实测的步骤）

1拉镜像

docker pull ghcr.io/open-webui/open-webui:main —— 5.82 GB，比想象的大得多

2启动

docker run -d --name owui -p 18081:8080 ghcr.io/open-webui/open-webui:main

3

等约 90 秒，打开 http://localhost:18081 ，第一个注册的账号自动成为管理员

4

接一个模型（Ollama 或任意 OpenAI 兼容接口），否则发不出对话
