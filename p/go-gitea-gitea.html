证据：官网 · 镜像地址 · API 文档

我看到了什么

  • 不设 INSTALL_LOCK 时容器停在安装向导，/api/v1/version 返回 404
  • 设了之后同一个接口立刻返回版本号 28.2.0
  • 管理员只能在容器里用命令行建，网页注册拿不到管理权限
  • API 建仓库返回 201，提交文件返回 201，读回来的内容与写入一致

全部是实测时的真实输出，不是转述

怎么用（我实测的步骤）

1拉镜像

docker pull gitea/gitea:latest —— 262 MB，这批里最轻

2启动

必须带上 -e GITEA__security__INSTALL_LOCK=true，否则会停在安装向导

3建管理员

docker exec -u git gitea gitea admin user create --username radar --admin ...

4

用 API 建仓库、提交文件、再读回来验证
