Ollama

ollama/ollama

★ 185,246 · 最近更新 2026-10-29 · 本地运行

✅ 可商用MIT国内可用A · 主推

在自己电脑上跑大模型，断网也能用，不用调任何接口

适合谁

开发者 / 通用

你需要准备

一台 16G 内存以上的电脑，最好有独立显卡

不适合谁

只有 8G 内存的轻薄本

我验证过吗

已经跑通 · 2026-10-30 · Docker 29.2.1 · arm64 · macOS · 镜像 7.15 GB · 版本 0.40.13

证据：官网 · 镜像地址 · OpenAI 兼容说明

我看到了什么

  • 镜像 7.15 GB，但模型本体只有 0.40 GB——大头是运行环境
  • qwen2.5:0.5b 生成 68 tokens 用 0.68 秒，约 100 tokens/s（纯 CPU）
  • 首次调用要先加载模型 0.8 秒，第二次才快
  • /v1/chat/completions 返回标准 OpenAI 结构，usage 里 prompt 36 / completion 28

全部是实测时的真实输出，不是转述

怎么用（我实测的步骤）

1拉镜像

docker pull ollama/ollama:latest —— 7.15 GB，比模型本身大得多

2启动

docker run -d --name ollama -p 18100:11434 ollama/ollama:latest

3拉模型

docker exec ollama ollama pull qwen2.5:0.5b —— 0.40 GB，实测 15 秒

4调用

POST /v1/chat/completions（OpenAI 兼容），或 /api/generate（自有接口）

完整安装手册 会员

  • 开机自启：重启之后不用手动再敲一遍
  • 数据放哪：模型 / 配置 / 缓存在哪个目录，怎么挪
  • 给同一局域网里的其他设备用（手机、另一台电脑）
  • 升级与回滚：换版本不把配置搞坏
  • 跑不动的时候按什么顺序排查（内存、显存、端口）

剩下的坑和调优 会员

docker run 完是空的：模型必须另外 pull，不 pull 只能看着接口报错 · 容器里只能 CPU 推理，Apple Silicon 用不上 Metal 加速（那是原生 app 才有的）；0.5B 小模型约 100 tokens/s，换成 7B 会慢到没法用 · 内存随模型增长：0.5B 实测占 683 MB，7B 至少要 5 GB 以上 · 首次对话要加载模型约 0.8 秒，之后才快；别把第一次的延迟当成性能
