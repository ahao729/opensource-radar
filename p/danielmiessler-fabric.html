证据：官网 · 下载页 · pattern 目录

我看到了什么

  • 发行包里没有 pattern：二进制能跑，但 --listpatterns 提示 No patterns found
  • 把仓库 data/patterns 下 344 个文件下下来后，识别出 265 个 pattern
  • echo 文本 | fabric -p summarize --dry-run 输出完整系统提示词（20 词摘要格式）

全部是实测时的真实输出，不是转述

怎么用（我实测的步骤）

1

下载官方 arm64 二进制：fabric_Darwin_arm64.tar.gz（27 MB），解压即用，无需 Docker

2

首次运行会找 ~/.config/fabric，没有就自己建目录放 .env

3

内置不含 pattern，需要另外准备 265 个 pattern 文件（官方仓库 data/patterns 目录）

4试跑

echo "文本" | fabric -p summarize --dry-run —— 只组装提示词，不发请求

完整安装手册 会员

  • 开机自启：重启之后不用手动再敲一遍
  • 数据放哪：模型 / 配置 / 缓存在哪个目录，怎么挪
  • 给同一局域网里的其他设备用（手机、另一台电脑）
  • 升级与回滚：换版本不把配置搞坏
  • 跑不动的时候按什么顺序排查（内存、显存、端口）
