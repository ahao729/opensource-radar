怎么用（我实测的步骤）

1拉镜像

docker pull n8nio/n8n:latest —— 1.81 GB

2启动

docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n:latest

3导入工作流

docker exec n8n n8n import:workflow --input=/tmp/wf.json

4执行工作流

另起一个一次性容器跑 n8n execute --id=<工作流ID>（不能在已运行的容器里跑）

剩下的坑和调优 会员

常驻内存 736 MB，2G 内存的机器再装别的会很紧 · n8n execute 不能在正在运行的容器里执行：Task Broker 端口 5679 已被占用，直接报 port already in use · 一次性容器不能写 docker run ... n8n execute，入口脚本会把 n8n 当成找不到的命令；必须加 --entrypoint n8n · 数据必须挂卷到 /home/node/.n8n，否则容器一删，工作流全没
